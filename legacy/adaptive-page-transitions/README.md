# Adaptive Page Transitions — retired experiment

Archived source: `0.3.0-preview.3` ([original commit](https://github.com/NoctHarborStudio/zen-refined-ui-improvements/commit/0e00da850b639041ffdf7d009705c5f81d83bc8e)). This is the earlier live-reveal implementation, not the later compositor rewrite. It was relatively usable on some sites but had known SPA and first-load rendering problems. Development was discontinued after the later experiments failed to provide reliable behavior.

The files are preserved as inert text, not as an installable Sine mod. The original theme ID and actor URLs are intentionally unchanged in the archived code; they would need reconfiguration to run again. No active manifest, CSS, preferences, or script refers to these files. Do not load them in the current mod.

The last discontinued compositor implementation (`0.4.0-preview.1`) remains available in Git history at [794974e](https://github.com/NoctHarborStudio/zen-refined-ui-improvements/commit/794974e71971513b8af30ad0c8f3d4d81859f8d2).

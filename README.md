# Zen Refined — legacy project

> **Discontinued as a standalone mod.** Zen Refined is now part of [Nocturne](https://github.com/NoctHarborStudio/zen-oneplane-horizontal-tabs), the unified successor to OnePlane and Zen Refined.

This repository is retained for historical reference and source inspection. All new development, bug fixes, documentation and releases belong to Nocturne. Do not install Zen Refined alongside Nocturne.

## Migration

If you already use OnePlane and Zen Refined, disable Zen Refined in Sine, restart Zen, then update OnePlane. The existing OnePlane entry becomes Nocturne. See [Nocturne installation and migration](https://github.com/NoctHarborStudio/zen-oneplane-horizontal-tabs#install-with-sine). Keep the legacy mod disabled until rollback has been tested.

## Historical documentation

- [Last standalone preview source and README](https://github.com/NoctHarborStudio/zen-refined-ui-improvements/tree/preview)

# Indicators — architecture and implementation pipeline

## Ownership and placement

- Zen Refined owns Downloads state, native dock icon, transient detail card and one-shot flight. OnePlane may supply a connected chrome host via `window.__zenRefinedDownloadIndicator.setHost(element)`, release with `setHost(null)`, or expose `#oneplane-download-indicator-slot` and dispatch `OnePlane:DownloadHostChanged`. Same node, no duplicate data subscription. `getSnapshot()` exposes aggregate state only, not names/paths.
- Native Zen: mount before top sidebar controls by structural identity. Follow `zen-right-side`. Hold the native sidebar only for a downloads surface opened via the sidebar indicator, through its closing animation, via the indicator's panelopen attribute (Zen owns zen-compact-mode-active). Automatic download notifications and interactions inside them never acquire that hold; All downloads preserves the opening source. Release only this owned attribute after close or teardown. Keep the icon in place during auto-hide; calculate the live inner toolbox edge from its translated DOMRect, clamp to window edge. OnePlane's optional host contract remains. Hide redundant footer Library only with native replacement.
- Recent and full downloads modes share a single root-level overlay. Independent positioning translate follows live inner edge with 8px clearance (6px viewport clamp); entrance/exit transform does not transition positioning. Automatic Recent mode holds 2000ms outside pointer hover; newest four by start time. Manual Recent and full modes have no auto-dismiss. One 430px surface, one row cache, in-place mode switch with 12px bottom margin. Click a row or All downloads to open the custom dock, not native Library; file actions do not open the dock. Dock shows active and recent native list entries, 30 at a time, Show in folder using native Download.showContainingDirectory(), close/Escape/outside click. Time sort is chronological, matching recent mode; size sort keeps active first and unknown sizes last; both are cached; Clear confirmation replaces header, Yes left/No right. Clear removes only stopped, non-partial, non-blocked native session-list entries via DownloadList.remove; no Places browsing-history deletion, finalize or file removal. No persistent history copy or file deletion. Open calls the native Download.launch() only on explicit user click for a completed existing target. Optional average speed and elapsed time are computed from observed completion and native startTime, including pauses; restored history has no invented statistics. Actual rendered sidebar paint (including available gradient), native outline, row and foreground are sampled on opening/mount; a bounded WAAPI cubic path morph grows a connected narrow stream from the icon to the far edge, then fills diagonally; closing reverses the same contour; a viewport mask clips the animation at the native sidebar edge; full mode clips only the added height and staged CSS content fade, no per-frame text scaling. The dock has a reserved scrollbar gutter and translucent native-painted background. The transparent outside catcher deliberately consumes the first click on webpage content; sidebar stays interactive.
- Flight: one bounded 780ms WAAPI animation (940ms fail-safe) using sampled click and icon coordinates; no per-frame JavaScript, no flight for restored history or unfocused windows. Reduced motion skips flight. Card retracts after 3000ms; transfer updates never restart timer.

## Data and render pipeline

1. One native privacy-specific Downloads list view per window. Initial history ignored; active transfers restored quietly.
2. Native events update active batch, filenames from basename only (never send/store paths), actual bytes, total speed and aggregate known progress. Coalesced ordinary visual updates at most 5 Hz. No polling or geometry reads on progress. Geometry updates only for structural/side changes, card/dock open and flight start, plus bounded animation-follow frames (typically 380–520ms) while overlays are visible. During follow frames read only the actual toolbox edge; cache overlay heights and vertical position. Render order is cached until a download enters/leaves the list or changes active state. No idle polling. Temporary native flight is visually suppressed; native underlying listener may still execute.
3. Page indicator: one tabs-progress listener, WeakMap state per browser; selected tab only. Top-level network events, known byte estimates at most ~8 Hz, unknown totals use fixed partial line with soft opacity pulse. CSS scales one line from center toward both sides; no percentage label. Success extends to full and fades; errors/cancel hide without fake completion. No screenshot or page injection.
4. Disable/unload invalidates async installs and removes DOM, event listeners, observers, flight and timers. No persistent download metadata.
